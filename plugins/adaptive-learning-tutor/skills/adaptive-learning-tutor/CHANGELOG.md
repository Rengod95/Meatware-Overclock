# Changelog

## 0.3.0 — 2026-09-23

하나의 표준 Agent Skills 진입점으로 통합했다. 개념·응용, 독립 심화, 분야 조망, 문제 추적, 후학습과 국소 복구를 지원하며 범위·깊이·형태를 분리한다. 후학습의 원본 복귀는 해당 분기에서만 필수다.

설명·기초·문장 원칙을 상황별 참조로 분리했다. 제작 전 확인을 기본값으로 보존하고 적응형 즉시 설명을 선택할 수 있도록 정책 우선순위를 명시했다. 사용자 상태는 기본 비활성이고 빈 근거로 시작한다.

Codex/Claude Code/Gemini CLI/Pi 및 사용자 지정 경로 설치를 추가했다. 기존 파일을 덮어쓰지 않고, 설치 기본은 미리보기다. 선택적 제작 계약 검사, 독립형 프롬프트의 재생성/동기 검사, 구조 검증과 회귀 시험을 추가했다.

원본 Tutor의 학습 상태 포맷 0.1.0을 보존했다. 두 원본 상태의 자동 마이그레이션, 실제 에이전트 호출·학습 효과 검증, 사용자 장치 설치는 수행하지 않았다.
