# 독자용 국소 설명 예시 — 현재 값과 과거 기록

이 예시는 특정 API나 도메인 사실이 아닌, 아래에 정한 가상 규칙만 사용한다. 실제 사용자 응답이나 학습 결과가 아니다.

## 가상 입력

“재고가 지금 5개라는데 지난 입고의 결과는 왜 3개라고 써 있어? 같은 재고를 말하는 것 아닌가?”

## 가능한 독자용 본문

처음 재고가 1개였고, 첫 입고에서 2개를 더 받아 3개가 되었다고 하겠습니다. 이때 첫 입고 기록에 남긴 3은 그 작업이 끝난 순간의 값입니다. 이후 다른 입고에서 2개를 더 받으면 현재 재고는 5가 됩니다. 두 숫자가 다른 것은 같은 순간을 서로 다르게 계산해서가 아니라, 서로 다른 순간의 값을 가리키기 때문입니다.

현재 재고는 “지금 몇 개가 있는가?”에 답합니다. 첫 입고 기록은 “그 작업 직후 몇 개가 되었는가?”에 답합니다. 대상의 이름이 모두 재고여도 질문의 시점이 다르면 값은 달라질 수 있습니다. 현재 값이 바뀌었다는 이유만으로 과거에 실제로 기록한 값까지 5로 바꿀 필요는 없습니다.

다만 화면이 3을 '현재 재고'라고 표시한다면 이야기가 달라집니다. 과거 값을 보존한 것이 문제가 아니라, 그 값을 어떤 질문의 답으로 보여 주는지가 맞지 않는 것입니다. 먼저 숫자를 바꾸기보다 그 값의 시점과 화면의 이름이 같은 뜻인지 확인해야 합니다.

## 작성자 메모

한 구분의 설명으로 닫았다. 별도 장기 과정·용어집·퀴즈를 만들지 않는다. 사용자가 이해했다는 기록도 생성하지 않는다. 더 긴 해설이 필요한 후속 질문이 있으면 그 관계만 확장한다.
