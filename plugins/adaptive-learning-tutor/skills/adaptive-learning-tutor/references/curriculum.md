# 분야 조망과 누적 학습

## 처음 보는 분야

분야가 다루는 대상·질문·행위·방법, 반복되는 구분, 제약, 평가 기준을 먼저 연결한다. 산업군에서는 업무와 이해관계자의 흐름이, 연구 분야에서는 질문·방법·증거·학파가 유용할 수 있다. 사용자가 사업·직무 목표를 말하지 않았으면 강제하지 않는다.

정형화된 용어는 실제 용례와 근거를 확인한다. 공인 표준, 널리 쓰이는 관행어, 지역·조직·하위 분야 용어, 논쟁적 명칭, 설명용 분류를 구분한다. 번역과 원어가 필요하면 함께 제공한다. 용어의 이름만 나열하지 말고 어떤 판단과 관계를 표현하는지 설명한다.

개념 관계 지도, 읽기 순서, 용어 참조는 다르다. 지도는 한눈에 분야를 조망하는 결과물로 완결될 수 있다. 지도 요청을 모든 하위 교재 제작의 승인으로 해석하지 않는다. 방향이 미정이면 탐구 갈래와 각 갈래의 질문을 제시하고 임의 일정은 만들지 않는다.

## 장기 경로가 필요한 경우

사용자가 누적 학습을 원할 때 단기 질문, 중기 다른 사례의 구분, 장기 탐구·책임 영역을 연결한다. 호기심·비업무 분야도 동등한 입력이다. 단일 업무 티켓으로 전체 커리큘럼을 매번 갈아엎지 않는다. 장기 목표가 없으면 '없음/미설정'을 존중한다.

새 자료 전에 기존 대표 설명의 재사용, 국소 수정, 사례 추가, 통합 또는 대체를 검토한다. 여러 사례가 같은 원리를 보여 주더라도 다른 메커니즘까지 동일시하지 않는다. 이름만 같은 도메인 용어를 자동 병합하지 않는다.

관계의 유형은 선수, 부분, 원인, 시간, 대조, 제약, 표상 대응, 증거·관점 등으로 구분한다. 읽기 경로에는 도입·심화·비교·적용·조회·재방문·대체 역할이 있다. 참조 링크는 필수 다음 장이 아니다.

## 파트 연결과 기초 유예

각 파트에서 들어올 때 가정한 관계(entry), 답할 질문, 새 관계, 근거·사례, 본문이 제공할 설명(exit), 다음 파트의 필요(bridge)를 짧게 설계한다. 본문에 이 필드들을 그대로 반복하지 않는다. 다음 파트가 갑자기 새로운 선수 관계를 요구하는지 검토한다.

현재 답에 필수인 기초는 본문에 공급한다. 독립된 더 깊은 탐구는 유예할 수 있다. 이때 지금 받아들이는 계약, 생략한 내부, 현재 모형의 한계, 다시 열 조건을 남긴다. 모든 하위 기초를 무한히 요구하지 않는다.

원본 버전이 바뀌면 연결 해설을 재검토 후보로 다룬다. 실제 확인 전 틀렸다고 단정하지 않고, 사용자 지식이 퇴보했다고 기록하지 않는다. 재검토는 실제 세션에서만 하며 자동 감시를 약속하지 않는다.
