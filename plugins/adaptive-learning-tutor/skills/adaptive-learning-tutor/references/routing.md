# 진입점·의도·범위·깊이의 선택

현재 업무를 몰라도 설명할 수 있다. 진입점은 독점적인 영구 모드가 아니라 지금 필요한 설명 기능이다. 한 요청에 개념+응용, 문제+심화 등이 함께 있을 수 있다. 사용자에게 매번 모드를 고르게 하지 않는다.

| 진입점 | 반드시 이어야 할 관계 | 완료 조건 | 피할 확장 |
|---|---|---|---|
| 개념·응용 | 무엇을 구분/해결하는가 → 의도와 표현 → 관계/작동 → 적용·비적용 조건 | 요청한 개념과 맥락의 대응을 설명 | 이름이 닮았다는 이유로 패턴 적용 선언, 전체 리팩터링 |
| 독립 심화 | 정의·전제 → 논증/메커니즘 → 반례·대안·한계·근거 | 선택한 질문의 핵심 연결을 본문에서 완결 | 현재 프로젝트 강요, 주변 모든 주제로 팽창 |
| 도메인 입문 | 대상·질문·행위자/방법 → 반복되는 구분 → 용어·관행·관점 → 하위 탐구 | 분야의 논의를 읽고 다음 질문을 고를 지도 제공 | 용어 나열, 자동 12주 계획, 전체 강의 선생성 |
| 문제 기반 | 정상 기준 → 증상·증거 → 후보 → 구별할 관찰 → 조치·결과 → 원리 | 해결/완화/원인 확인 범위를 분리 | 단서 하나로 원인 확정, 해결을 강의 뒤에 숨김 |
| 산출물 후학습 | 실제 자료·버전 → 제약·기록된 결정 → 원리·대안 → 원본 재대응 | 결정/코드/문장과 일반 관계의 왕복 | 실제 의도 발명, 원문 전체 요약, 무조건 교재화 |
| 국소 복구 | 마지막 이해 → 최초 단절 → 필요한 다리 → 원래 관계 | 끊긴 부분을 좁게 보충 | 전체 진단·교재 반복 |

각 경로의 완료는 설명이 제공한 범위다. 사용자가 그 관계를 습득했다는 뜻이 아니다.

## 독립적인 축

진입점과 함께 목적(탐구/구분/설명/적용/판단), 범위(한 관계/한 개념/분야 지도), 깊이(필요성/기제/전제/대안/경계/근거), 장르, 표상, 매체, 분량 제약, 연속성을 따로 결정한다. 범위를 넓힌 것을 깊어진 것으로 부르지 않는다. 3문단 안의 깊은 구분과 장문의 논증이 모두 가능하다.

짧게 만들 때 반복·장식·곁가지를 먼저 줄이고 필수 인과·논증 연결은 유지한다. 제약 안에 모든 요구가 들어가지 않으면 설명한 범위와 남은 범위를 밝힌다. '적정 크기'는 무조건 짧게 쓰라는 뜻이 아니다.

## 혼합·전환

빌더 패턴의 개념과 현재 패키지 응용을 함께 물으면 개념 설명과 적용 검토를 모두 수행한다. 실제 파일이 없으면 일반 원리와 가상 적용을 구분하고, 기존 코드 분석을 발명하지 않는다. 단계적 작성에 대한 비유와 소프트웨어 구조 구현도 구분한다.

분야 지도 → 선택한 개념 심화 → 막힌 문장 보충 → 다른 사례 비교로 이동할 수 있다. 이미 공급한 관계와 용어는 이어받지만 과거 업무를 모든 새 질문에 끼우지 않는다. '이 사건과 관계없이 더 배우자'는 독립 탐구로의 실제 범위 변경이다.

역사·문학·철학·사회과학 등에는 기계적 오류–해결 서사를 강제하지 않는다. 자료·관점·주장·논거의 차이를 다룬다. 분야에 적용되는 정확성·안전·정치적 중립 등 호스트의 정책은 그대로 유지한다.
