# 출처·변경 이력과 한계

작성일: 2026-09-23. 입력은 사용자가 업로드한 `learning-design-orchestrator.zip`, `sustainable-learning-tutor-v0.1.0.zip`와 현재 대화의 수정 요구다. 원본 ZIP은 수정하지 않았다. 아카이브 해시는 [source-manifest.json](source-manifest.json)에 있다.

관련 SKILL, 맥락 진단, 장르, 교수 설계, 글쓰기, 커리큘럼, 승인·검수, 상태 스키마와 도구·테스트를 검토했다. 연구 보관본의 모든 외부 문헌을 재검증한 것은 아니다. 이 패키지에 새롭게 붙인 규칙·우선순위는 설계 결정이며 검증된 보편 학습법이라고 주장하지 않는다.

복제/수정 범위: `scripts/tutor_state.py`, `assets/state.schema.json`, `tests/test_state.py`는 Tutor 기반이다. 상태 도구의 모듈 설명은 새 패키지명을 사용한다. 기본 상태는 개인 근거와 업무 중심 장기 목표를 제거했다. `references/context-diagnosis.md`는 Orchestrator의 후보 목록과 맥락 수집 구조를 통합했으며 저장 label 차이와 근거 표기를 수정했다. 나머지 지침·설치·선택적 제작 계약·추가 시험·예시는 새 통합안이다.

## 이전 생성물의 취급

과거 응답에 나온 v0.1/v0.2 다운로드 경로는 현재 마운트와 파일 검색에서 다시 확인되지 않았다. 그 파일을 모두 열어 병합했다고 표현하지 않는다. 현재 대화에 남은 사용자 요구와 설계 설명을 재구성하고, 실제 확인한 원본 파일을 기반으로 새 패키지를 생성했다.

## 사용과 재배포

원본 ZIP에는 명시적인 LICENSE 파일이 보이지 않아 이 통합본에 임의로 MIT 등의 라이선스를 부여하지 않았다. 사용자가 제공한 자료를 개인 사용을 위해 통합한 패키지이며 외부 문헌 본문을 재출판하지 않는다. 새 공개 배포에 필요한 권리·라이선스 판단을 대신했다는 의미는 아니다.

## 검증 수준

실제 로컬 코드/구조 검사와 모델의 행동 시험, 실제 사람의 학습 효과는 별개다. 결과는 VALIDATION.md에 구분한다. 합성 테스트와 독서 예시를 실제 사용자의 이해·승인·응답 기록에 넣지 않는다.
