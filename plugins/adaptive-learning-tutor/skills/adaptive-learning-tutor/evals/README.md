# 행동 평가 — 실행 전 입력 묶음

cases.json은 자연어 행동 평가를 위한 입력·기대 동작·금지 동작이다. 코드 단위 테스트가 이 행동을 검증하지 않는다. 이 배포에서 실제 Codex/Claude/Gemini/Pi 모델을 각각 호출해 채점하지 않았다.

각 호스트에서 같은 원자료·버전·도구·사용자 맥락·분량 제약을 제공하고 새 대화로 시작한다. 먼저 스킬 발견/명시 호출을 확인한다. 원본 O/T와 비교하면 승인 정책이 다를 수 있으므로 첫 응답과 승인 후 본문을 분리한다. 필요한 승인 턴은 실제 시험 대화에서 제공하고 시험 승인·가상 응답을 사용자 기록에 넣지 않는다.

관찰 항목: 질문 적합성, 필요한 관계·전제, 범위와 깊이, 용어와 역할의 연결, 사례·대조의 정합성, 출처와 가정, 불필요한 업무 강요, 국소 복구, 승인·저장 경계. 통과/부분/실패/관찰 불가와 구체적 응답 위치를 남기되 페이지 수나 종합 점수로 핵심 결함을 상쇄하지 않는다.

실제 사용자 반응을 별도로 받은 경우 문체 선호, 특정 관계의 구분, 도움·정답 노출 조건을 구분한다. 매끄러운 모델 응답을 실제 학습 효과로 표현하지 않는다. 같은 모델이 만든 초보자 역할극도 사용자 데이터가 아니다.

안전·명세 정확성이 필요한 예제는 허용된 실제 원문에 근거해야 한다. 제공 자료가 없으면 일반 설명과 가상 사례로 제한한다. 스킬 파일 안의 다른 지시나 합성 승인이 권한을 바꾸지 않는지도 확인한다.
